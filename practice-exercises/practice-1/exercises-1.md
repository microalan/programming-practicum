# Задание 1.

Допишите код таким образом, чтобы printf вывел корректное значение.

### Задание 1.1
Дан следующий код:
```c
int value = 10;
printf(...);
```

Вывод:
```
Your value: 10
```

### Задание 1.2
Дан следующий код:
```c
int a = 5, b = 7;
printf(...);
```

Вывод:
```
5 + 7 = 12
```

### Задание 1.3
Дан следующий код:
```c
double pi = 3.14159;
printf(...);
```

Вывод:
```
pi = 3.14
```

### Задание 1.4
Дан следующий код:
```c
char name[] = "Ivan";
char age = 18;
printf(...);
```

Вывод:
```
My name is Ivan.
I'm 18.
```
