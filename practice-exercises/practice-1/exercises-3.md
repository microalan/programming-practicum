# Задание 3. 

Решите задачи.

### Задание 3.1
Пользователь вводит два числа, вывести какое из них большее в виде условного выражения (или сообщить, что равны).

Пример вывода:
```
10 > 3
```
или
```
2 < 5
```
или
```
1 = 1
```

### Задание 3.2
Пользователь вводит натуральное значение N. Найти сумму чисел от 1 до N.


### Задание 3.3
Пользователь вводит натуральное значение N, а затем N целых чисел. Найти произведение чётных чисел.

### Задание 3.4
Пользователь вводит размеры матрицы. Вывести на экран матрицу из нулей.

Пример вывода для матрицы 3x3:
```
0 0 0
0 0 0
0 0 0
```

### Задание 3.5
Пользователь вводит размеры матрицы. Вывести на экран матрицу в виде "шахматной доски" - белые клетки обозначить как `-`, а чёрные как `+`.

Пример вывода для матрицы 3x3:
```
+ - +
- + -
+ - +
```
