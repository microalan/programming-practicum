# Задание 2. 

Напишите функции согласно заданиям. Проверьте работу функций.


### Задание 2.1
Напишите функцию, которая подсчитывает длину строки (аналог strlen).

### Задание 2.2
Напишите функцию, которая печатает строку задом наперёд.

### Задание 2.3
Пользователь задаёт два символа (x1 и x2) и строку. Написать функцию, которая заменяет в строке все символы x1 символами x2. 

### Задание 2.4
Пользователь задаёт строку и шаг. Написать функцию, которая выводит символы строки с заданным шагом.

### Задание 2.5
Напишите функцию, которая сравнивает две строки (возвращает значение равно/не равно).

### Задание 2.6
Пользователь вводит строку. Написать функцию, которая копирует текст из заданной строки в новую строку без пробелов.
