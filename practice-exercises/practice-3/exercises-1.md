# Задание 1. Поиск ошибок


Найдите ошибки в коде.


### Задание 1.1
```c
int x = 5
printf("%d", x);
```

<details>
<summary>Ответ</summary>

Пропущена `;` в первой строке.
</details>


### Задание 1.2
```c
float a;
scanf("%f", a);
```

<details>
<summary>Ответ</summary>

Пропущен `&` перед переменной в scanf.
</details>


### Задание 1.3
```c
int a = 10;
if (a = 5) printf("Equal");
```

<details>
<summary>Ответ</summary>

В условии присваивание `=` вместо сравнения `==`.
</details>


### Задание 1.4
```c
for (int i = 0, i < 10, i++)
    printf("%d", i);
```

<details>
<summary>Ответ</summary>

В цикле for должна быть `;` вместо `,`
</details>


### Задание 1.5
```c
int i = 0;
while (i < 5) {
    printf("%d", i);
}
```

<details>
<summary>Ответ</summary>

Не изменяется `i` - бесконечный цикл. Нужен `i++` в теле цикла.
</details>


### Задание 1.6
```c
int a[5] = {1, 2, 3, 4, 5, 6};
```

<details>
<summary>Ответ</summary>

Инициализаторов больше, чем элементов массива.
</details>


### Задание 1.7
```c
int a[5];
for (int i = 1; i <= 5; i++)
    a[i] = i;
```

<details>
<summary>Ответ</summary>

Индексация с `1` и `i <= 5` - выход за границу. Правильно: `i = 0; i < 5`.
</details>


### Задание 1.8
```c
int a[5] = {1, 2, 3, 4, 5};
int sum;
for (int i = 0; i < 5; i++)
    sum += a[i];
```

<details>
<summary>Ответ</summary>

`sum` не инициализирована - накапливается «мусор». Нужно `int sum = 0;`.
</details>


### Задание 1.9
```c
int m[2][3];
for (int i = 0; i < 2; i++)
    for (int j = 0; j < 3; i++)
        m[i][j] = 0;
```

<details>
<summary>Ответ</summary>

Во внутреннем цикле инкрементируется `i`, а не `j` - бесконечный цикл.
</details>


### Задание 1.10
```c
int a[5] = {1, 2, 3, 4, 5};
for (int i = 0; i < 5; i++)
    a[i] = a[i + 1];
```

<details>
<summary>Ответ</summary>

На последней итерации читается `a[5] (a[i+1])` - выход за границу.
</details>

## Некорректные решения

### Задание 1.11
**Задача**: посчитать количество чётных элементов массива.
```c
int a[6] = {1, 2, 3, 4, 5, 6};
int cnt = 0;
for (int i = 0; i < 6; i++)
    if (a[i] % 2 == 1) cnt++;
```

<details>
<summary>Ответ</summary>

Считаются нечётные, а не чётные. Должно быть `a[i] % 2 == 0`.
</details>


### Задание 1.12
**Задача**: вывести все элементы массива в обратном порядке.

```c
int a[5] = {1, 2, 3, 4, 5};
for (int i = 4; i > 0; i--)
    printf("%d ", a[i]);
```

<details>
<summary>Ответ</summary>

Последний элемент не выводится. Должно быть `i >= 0`.
</details>


### Задание 1.13
**Задача**: найти среднее арифметическое элементов массива.

```c
int a[5] = {1, 2, 3, 4, 5};
int sum = 0;
for (int i = 0; i < 5; i++) {
    sum += a[i];
}
printf("%f", sum / 5);
```

<details>
<summary>Ответ</summary>

Целочисленное деление `sum / 5` даёт `int`, а `%f` ждёт float - вывод некорректен. Нужно `(float)sum / 5`.
</details>


### Задание 1.14
**Задача**: проверить, есть ли в массиве элемент, равный 7.

```c
int a[5] = {1, 7, 3, 4, 5};
int found = 0;
for (int i = 0; i < 5; i++) {
    if (a[i] == 7) found = 1;
    else found = 0;
}
printf("%d", found);
```

<details>
<summary>Ответ</summary>

Флаг `found` перезаписывается на каждой итерации - итог зависит от последнего элемента. Нужно выставлять `found = 1` без `else`.
</details>


### Задание 1.15
**Задача**: развернуть массив (переставить элементы в обратном порядке).

```c
int a[5] = {1, 2, 3, 4, 5};
for (int i = 0; i < 5; i++){
    int tmp = a[i];
    a[i] = a[4 - i];
    a[4 - i] = tmp;
}
```

<details>
<summary>Ответ</summary>

Массив остаётся в исходном виде, т.к. разворачивается повторно. Цикл должен быть до середины - `i < 5/2`.
</details>
