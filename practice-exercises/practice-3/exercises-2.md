# Задание 2. 

Напишите функции согласно заданиям. Проверьте работу функций.


### Задание 2.1
Напишите функцию нахождения квадрата числа.

### Задание 2.2
Напишите функцию, которая возвращает большее из двух переданных ей целых чисел.

### Задание 2.3
Напишите функцию возведения числа в степень.

### Задание 2.4
Напишите функцию нахождения факториала числа.

### Задание 2.5
Напишите функцию заполнения одномерного массива и функцию вывода его элементов.

### Задание 2.6
Напишите функцию нахождения суммы элементов одномерного массива.

### Задание 2.7
Напишите функцию поиска индекса элемента в одномерном массиве. Если заданного элемента нет, то функция должна возвращать -1.

### Задание 2.8
Напишите фунцию поиска минимального и максимального элементов одномерного массива.

### Дополнительно
Выполнить задания 2.5-2.8 для двумерного массива.
