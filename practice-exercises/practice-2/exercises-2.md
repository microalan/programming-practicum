# Задание 2. 

Решите задачи.

## Одномерные массивы

### Задание 2.1
Запросите у пользователя длину одномерного массива n. Заполните его нулями.
Выведите массив на экран.

### Задание 2.2
Заполните массив значениями от 1 до n.

### Задание 2.3
Дайте пользователю заполнить массив значениями.

### Задание 2.4
Пользователь вводит целочисленное значение x. Увеличьте элементы массива на x.

### Задание 2.5
Замените все отрицательные элементы массива на 0.

### Задание 2.6
Проверьте, является ли массив полиндромом.


## Двумерные массивы

### Задание 2.7
Запросите у пользователя размер двумерного массива n. Создайте двумерный массив (квадратную матрицу) размером n×n. Заполните его следующим образом:
```
1 2 3 ... n
1 2 3 ... n
...
1 2 3 ... n
```
Выведите массив на экран.

### Задание 2.8
Заполните главную диагональ квадратной матрицы нулями.

### Задание 2.9
Найдите сумму элементов побочной диагонали.

### Задание 2.10
Пользователь задаёт размеры матрицы m×n и ее элементы. Создайте одномерный массив размером m и заполните его произведением строк матрицы.
