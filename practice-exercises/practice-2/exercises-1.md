# Задание 1. "Перевод с русского на C"


Напишите строку (строки) кода по их описанию.

### Задание 1.1
Подключите библиотеку ввода-вывода.

<details>
<summary>Ответ</summary>

```c
#include <stdio.h>
```
</details>

Обьявите функцию **main** без параметров, с типов возвращаемого значения **int**.

<details>
<summary>Ответ</summary>

```c
int main() {

}
```
</details>


### Задание 1.3
Объявите вещественную переменную **x**.

<details>
<summary>Ответ</summary>

```c
float x;
```
</details>


### Задание 1.4
Обьявите константную целочисленную переменную **size** и инициализируйте её значением 64.

<details>
<summary>Ответ</summary>

```c
const int size = 64;
```
</details>


### Задание 1.5
Выведите на экран значение целочисленной переменной **x**.

<details>
<summary>Ответ</summary>

```c
printf("%d", x);
```
</details>


### Задание 1.6
Считайте два целых числа в переменные **a** и **b**.

<details>
<summary>Ответ</summary>

```c
scanf("%d %d", &a, &b);
```
</details>


### Задание 1.7
Увеличьте значение **x** в 2 раза.

<details>
<summary>Ответ</summary>

```c
x*=2;
```
</details>


### Задание 1.8
Измените знак переменной **x** на противоположный.

<details>
<summary>Ответ</summary>

```c
x = -x;
```
</details>


### Задание 1.9
Если **x** больше 0, выведите значение **x**.

<details>
<summary>Ответ</summary>

```c
if (x > 0) {
    printf("%d", x);
}
```
</details>


### Задание 1.10
Если значение **x** находится в диапазоне от 1 до 10 включительно, то выведите сообщение **"Correct!"**

<details>
<summary>Ответ</summary>

```c
if (x >= 1 && x <= 10) { 
    print("Correct!"); 
}
```
</details>


### Задание 1.11
Пока **x** больше 0 — уменьшайте его значение на на 1.

<details>
<summary>Ответ</summary>

```c
while (x > 0) {
    x--;
}
```
</details>


### Задание 1.12
Считывайте целые числа, пока не будет введён 0.

<details>
<summary>Ответ</summary>

```c
while (x != 0) { 
    scanf("%d", &x); 
}
```
</details>


### Задание 1.13
Переберайте целые числа, начиная с 1, пока не найдёте число, делящееся на **num** без остатка.

<details>
<summary>Ответ</summary>

```c
int i = 1; 
while (i % num != 0) {
    i++; 
}
```
</details>


### Задание 1.14
Выведите все чётные числа от 0 до n.

<details>
<summary>Ответ</summary>

```c
for (i = 0; i <= n; i++) {
    if (i % 2 == 0) {
        printf("%d", i);
    }
}
```
</details>


### Задание 1.15
Считывайте числа до тех пор, пока их сумма меньше 100.

<details>
<summary>Ответ</summary>

```c
while (s < 100) { 
    scanf("%d", &x); 
    s += x; 
}
```
</details>
