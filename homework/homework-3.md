## Задание 1. Простые функции 

### 1. Пример задачи и решения:

**Условие**: Напишите функцию, которая возвращает модуль целого числа. Проверьте работу функции.


**Решение**:
```c
#include <stdio.h>

int abs_value(int x)
{
    if (x < 0) {
        return -x;
    }
    return x;
}

int main()
{
    printf("%d\n", abs_value(-7));
    printf("%d\n", abs_value(0));
    printf("%d\n", abs_value(42));
    return 0;
}
```

## Задание 2. Простые функции ч.2

### 1. Пример задачи и решения:

**Условие**: Напишите функцию, которая находит сумму цифр заданного числа. Проверьте работу функции.


**Решение**:
```c
#include <stdio.h>

int digit_sum(int n)
{
    n = abs_value(n); // получаем модуль

    int sum = 0;
    while (n > 0) {
        sum += n % 10;
        n /= 10;
    }
    return sum;
}

int main()
{
    printf("%d\n", digit_sum(1234));
    printf("%d\n", digit_sum(0));
    printf("%d\n", digit_sum(-507));
    return 0;
}
```

## Задание 3. Передача параметров по указателю.

**Условие**: Напишите функцию обмена значениями двух целых чисел. Проверьте работу функции.


**Решение**:
```c
#include <stdio.h>

void swap(int *a, int *b)
{
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

int main()
{
    int x = 3, y = 8;
    printf("Before: x=%d, y=%d\n", x, y);
    swap(&x, &y);
    printf("After:  x=%d, y=%d\n", x, y);
    return 0;
}
```

## Задание 4. Передача массивов в функцию.

### 1. Пример задачи и решения:

**Условие**: Напишите функцию, которая считает, сколько элементов массива являются чётными. Проверьте работу функции.


**Решение**:
```c
#include <stdio.h>

int count_even(const int *arr, int n)
{
    int count = 0;
    for (int i = 0; i < n; i++) {
        if (arr[i] % 2 == 0) {
            count++;
        }
    }
    return count;
}

int main()
{
    int a[] = {4, 7, 10, 3, 8, 9};
    int b[] = {1, 3, 5};

    printf("%d\n", count_even(a, 6));
    printf("%d\n", count_even(b, 3));
    return 0;
}
```

### 2. Решите задачу:

## Задание 5. Передача массивов в функцию ч.2.

### 1. Пример задачи и решения:

**Условие**: Напишите функцию, которая для двумерной матрицы целых чисел находит сумму элементов в каждой строке и записывает эти суммы в переданный одномерный массив. Проверьте работу функции.


**Решение**:
```c
#include <stdio.h>

#define MAX 100

void read_matrix(int arr[][MAX], int rows, int cols)
{
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            scanf("%d", &arr[i][j]);
        }
    }
}

void row_sums(int arr[][MAX], int rows, int cols, int *sums)
{
    for (int i = 0; i < rows; i++) {
        int s = 0;
        for (int j = 0; j < cols; j++) {
            s += arr[i][j];
        }
        sums[i] = s;
    }
}

int main()
{
    int arr[MAX][MAX];
    int sums[MAX];
    int rows, cols;
    printf("Enter rows & cols: ");
    scanf("%d %d");

    read_matrix(arr, rows, cols);

    row_sums(arr, rows, cols, sums);

    for (int i = 0; i < rows; i++) {
        printf("%d ", sums[i]);
    }
    return 0;
}
```

### 2. Решите задачу:
**Условие**: Напишите функцию, которая для каждой строки матрицы считает количество чётных элементов и записывает результаты в одномерный массив. Проверьте работу функции.
