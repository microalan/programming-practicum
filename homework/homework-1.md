## Задание 1. Арифметические операторы, ввод-вывод

### 1. Пример задачи и решения:

**Условие**: Пользователь вводит два целых числа a и b. Выведите на экран их сумму, разность, произведение, частное (целочисленное деление) и остаток от деления.


**Решение**:
```c
#include <stdio.h>

int main() {
    int a, b;

    printf("Enter 2 integers: ");
    scanf("%d %d", &a, &b);

    printf("Sum: %d\n", a + b);
    printf("Difference: %d\n", a - b);
    printf("Product: %d\n", a * b);
    printf("Quotient: %d\n", a / b);
    printf("Remainder of division: %d\n", a % b);

    return 0;
}
```

### 2. Решите задачу:
**Условие**: Пользователь вводит длину и ширину прямоугольника (вещественные числа). Вычислите и выведите его периметр и площадь.


## Задание 2. Условный оператор if-else

### 1. Пример задачи и решения:
**Условие**: Пользователь вводит три целых числа. Найдите и выведите наибольшее из них.

**Решение**:

```c
#include <stdio.h>

int main() {
    int a, b, c;
    int max;

    printf("Enter 3 integers: ");
    scanf("%d %d %d", &a, &b, &c);

    if (a >= b && a >= c) {
        max = a;
    } else if (b >= a && b >= c) {
        max = b;
    } else {
        max = c;
    }

    printf("Maximum: %d\n", max);

    return 0;
}
```

### 2. Решите задачу:
**Условие**: Пользователь вводит целое число. Определите, положительное оно, отрицательное или равно нулю, и выведите соответствующее сообщение.


## Задание 3. Цикл while ч.1

### 1. Пример задачи и решения:

**Условие**: Пользователь вводит целое положительное число n. Выведите на экран все целые числа от 1 до n включительно, каждое с новой строки.

**Решение**:
```c
#include <stdio.h>

int main() {
    int n;

    printf("Enter a positive integer: ");
    scanf("%d", &n);

    int i = 1;
    while (i <= n) {
        printf("%d\n", i);
        i++;
    }

    return 0;
}
```

### 2. Решите задачу:

## Задание 4. Цикл while ч.2

### 1. Пример задачи и решения:

**Условие**: Пользователь вводит целые числа одно за другим. Ввод продолжается до тех пор, пока не будет введён 0. Программа должна посчитать и вывести сумму всех введённых чисел.

**Решение**:

```c
#include <stdio.h>

int main() {
    int value;
    int sum = 0;

    printf("Enter integers (0 to stop):\n");

    while (1) {
        scanf("%d", &value);

        if (value == 0) {
            break;
        }

        sum += value;
    }

    printf("Sum: %d\n", sum);

    return 0;
}
```

### 2. Решите задачу:
**Условие**: Пользователь вводит целые числа одно за другим. Ввод продолжается до тех пор, пока не будет введён 0. Программа должна найти и вывести наибольшее из введённых чисел (сам 0 не учитывается).


## Задание 5. Цикл for ч.1

### 1. Пример задачи и решения:

**Условие**: Пользователь вводит целое положительное число n. Выведите на экран сумму всех целых чисел от 1 до n включительно.

**Решение**:

```c
#include <stdio.h>

int main() {
    int n;
    int sum = 0;

    printf("Enter a positive integer: ");
    scanf("%d", &n);

    for (int i = 1; i <= n; i++) {
        sum += i;
    }

    printf("Sum: %d\n", sum);

    return 0;
}
```

## Задание 6. Цикл for ч.2

### 1. Пример задачи и решения:

**Условие**: Пользователь вводит два целых положительных числа a и b (a <= b). Программа должна найти первое число в диапазоне от a до b, которое делится на 7, и вывести его. Если такого числа нет - вывести сообщение об этом.

**Решение**:

```c
#include <stdio.h>

int main() {
    int a, b;
    int found = 0;

    printf("Enter two positive integers (a <= b): ");
    scanf("%d %d", &a, &b);

    for (int i = a; i <= b; i++) {
        if (i % 7 == 0) {
            printf("First multiple of 7: %d\n", i);
            found = 1;
            break;
        }
    }

    if (!found) {
        printf("No multiples of 7 in the range.\n");
    }

    return 0;
}
```

### 2. Решите задачу:
**Условие**: Пользователь вводит целое положительное число n > 1. Если оно не простое, то выведите все его делители. Если оно простое, то выведите соответствующее сообщение.


## Задание 7. Цикл for ч.3 (вложенный цикл)

### 1. Пример задачи и решения:

**Условие**: Пользователь вводит целое положительное число n. Выведите на экран прямоугольный треугольник из символов `*` высотой n строк: в первой строке - один символ, во второй - два, …, в n-й - n.

**Решение**:
```c
#include <stdio.h>

int main() {
    int n;

    printf("Enter a positive integer: ");
    scanf("%d", &n);

    for (int row = 1; row <= n; row++) {
        for (int col = 1; col <= row; col++) {
            printf("*");
        }
        printf("\n");
    }

    return 0;
}
```

**Пример вывода для n=4**:
```
*
**
***
****
```

### 2. Решите задачу:
**Условие**: Пользователь вводит целое положительное число n. Выведите на экран *перевёрнутый* прямоугольный треугольник из символов `#` высотой n строк: в первой строке - n символов, во второй - n-1, …, в последней - один.

**Пример вывода для n=4**:
```
####
###
##
#
```
